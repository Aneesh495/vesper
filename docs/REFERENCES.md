# Research references

- Radiometry, sampling measures, scattering and light transport. [Physically Based Rendering, fourth edition](https://www.pbr-book.org/4ed/contents)
- Vulkan compute, descriptors and synchronization contracts. [Khronos Vulkan Registry](https://registry.khronos.org/vulkan/)
- Exact table and redistribution metadata. [CIE 1931 2-degree observer](https://cie.co.at/datatable/cie-1931-colour-matching-functions-2-degree-observer)
- The temporal transport framework and arrival convention context. [Jarabo et al.](https://cs.dartmouth.edu/~wjarosz/publications/jarabo14framework.html)
- Independent forward and inverse rendering reference for future matched experiments. [Mitsuba 3](https://mitsuba.readthedocs.io/), [Mitsuba 2 paper](https://rgl.epfl.ch/publications/NimierDavidVicini2019Mitsuba2)
- Transient independent comparison resource. [mitransient](https://github.com/diegoroyo/mitransient)
- Scanline export layout. [OpenEXR file layout](https://openexr.com/en/latest/OpenEXRFileLayout.html)
