# Contributing

Build and run the focused numerical check for the affected estimator before opening a change. Run make test and make docs for changes to the shared library or build. Keep GPU layout edits paired with the corresponding shader and host static assertions. Preserve a CPU-only build and use a named hardware run for changes that affect dispatch, synchronization or numeric precision.

Scene assets must be authored or carry explicit redistribution provenance. Add new diagnostic claims to the experiment plan with frozen tolerances, sample counts and a separate expected value. Store large run artifacts outside Git. Keep deterministic probes and data preparation scripts alongside the relevant source.
