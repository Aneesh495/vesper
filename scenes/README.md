# Scene studies

| Scene | Mechanism | Finite pulse study |
|---|---|---|
| Afterglow | Diffuse room, spectral conductor, glass and area MIS | Mixed source spectrum and arrival gates |
| Veil | Trilinear density grid, null tracking, anisotropic scattering | Arrival broadening in a heterogeneous medium |
| Prism | Closed OBJ prism and dispersive group delay | Narrowband propagation through a wedge |
| Meridian | Nested dispersive interfaces and a tinted interior | Optical path length across two dielectric shells |
| Iris | Lens sampling against a named pinhole camera | Depth-dependent source contributions |
| Shutter | Translated geometry and emitter across an open shutter | Exposure blur and propagation delay |
| Lantern | A bounded homogeneous scattering medium and transparent shadow boundary | Volumetric direct-light connections |
| Furnace | Equal-energy environment over diffuse reflectances | Steady-state reference |
| Metalwork | Three roughness levels under a broad area source | Glossy reflection from a finite source |
| Frost | Rough and smooth glass with identical index curves | Transmission and rough-path delay |
| Needle | Narrow emitter and small target for light/spectral sampling | Narrow spectral peak and pulse |
| Array | 144 independently selected narrowband point emitters | Sequential pulse pattern |

Every material spectrum here is synthetic. The camera response uses the pinned observer table.
